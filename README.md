# tannerspaulding.github.io

Home page for tannerspaulding.com, currently the Futobi Labs home (Test Print look). `futobi/descent.html` is the Descent prototype shown in its live window. Published by GitHub Pages straight from the `main` branch on every push. The `CNAME` file sets the custom domain.

The labs moved to the [futobi-labs](https://github.com/futobi-labs) organization and live at https://labs.tannerspaulding.com. `404.html` and the `dataviz-lab/` and `datamodel-lab/` stubs forward old tannerspaulding.com lab links (any page under those paths) to the same path on labs.tannerspaulding.com.
